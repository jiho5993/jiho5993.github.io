채팅 웹 어플리케이션

  1. 2019.04 ~ 2019.06

Project information

  • 구성원: backend(1명), frontend(1명)
  • 프로젝트 기간: 2019.04 ~ 2019.06
  • Github: https://github.com/jiho5993/open_source_chat_B-02
  • Result: https://os-chat-b02.herokuapp.com

Project Stack

프로젝트에 사용된 기술 스택입니다.

Express.js

가벼운 코드로 웹 서버를 구현할 수 있다는 장점과 함께, 코드의 자유도가 높아 프로젝트 구조를 개발자의 마음대로 쉽게 구성할 수 있습니다.

Socket.io

실시간 양방향 통신을 위해 사용했습니다.
WebSocket이라는 모듈도 있지만, 오래된 브라우저는 지원하지 않는다고 해서 제외하고 socket.io를 채택했습니다.

Heroku

서버 요청이 없으면 잠시 꺼진다는 단점이 있지만, 무료 호스팅이라는 점과 프로젝트를 업로드하기만 하면 쉽게 배포할 수 있다는 점에서 채택했습니다.

Project Content

프로젝트에 구현한 주요 기능입니다.

# Socket.io를 활용한 실시간 양방향 통신 구현

  • * 실시간 채팅 구현이 주 목적이기 때문에 Socket.io으로 여러 이벤트를 등록하여 처리했습니다.
  • * 10개의 채팅 방을 생성하고 같은 방에 존재하는 사람끼리 채팅을 할 수 있도록 했습니다.

# Heroku 배포


느낀 점

프로젝트를 진행하면서 느낀 부분을 적었습니다.

  • 1. Socket.io 기능 구현에 많은 시간이 걸렸습니다.
    event name에 대한 개념이 잡혀있지 않아 클라이언트와 서버간의 event를 찾을 수 없어 의도한대로 구현이 되지 않았습니다.
    인터넷에 있는 코드를 그대로 따라치지말고 '각 기능이 어떻게 돌아가는지' 또는 '어떻게 사용해야 하는지'라도 알아야 함을 느꼈습니다.
    구현했지만, 개념이 잘 잡혀있지 않으면 어떻게 만든건지도 이해할 수 없다고 생각했습니다.

  • 2. 기존 프로젝트 팀원 수는 5명이었지만, 참여하지 않는 태도를 가진 3명이 프로젝트를 그만뒀습니다.
    그 당시에는 구현할 부분이 많지 않았으니 2명이서 어떻게든 되겠지라는 생각을 가졌지만, 실제로는 매우 힘들었습니다.
    한 사람 분의 몫을 해내기 위해선 프로젝트를 참여하려는 적극적인 태도가 중요하다는 것을 깨달았습니다.
