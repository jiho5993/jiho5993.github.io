Project Stack

프로젝트에 사용된 기술 스택입니다.

Django

챗봇 스킬 서버와 인공지능 개발을 위해 파이썬을 사용해야 했고,
단순하고 가벼운 flask에 비해, django는 web application을 개발하기 위한 대부분의 기능을 갖췄기에 채택했습니다.

Kakao i open builder

Kakao i open builder를 사용하여 챗봇에 필요한 기능을 구현할 수 있도록 했습니다.
시나리오, 엔티티, 스킬 서버 등을 사용하여 서버가 응답한 내용이 챗봇으로 보여줄 수 있도록 합니다.

beautifulsoup

적당한 로고가 없어 수프 사진으로 대체했습니다..
API가 호출될 때, 사이트의 정보를 추출하고 보여주기 위해 사용했습니다.

Docker

파이썬의 버전이나 다른 의존되는 모듈의 버전이 다르면 환경을 구축하기 매우 까다로웠습니다.
이에 배포환경에서 환경 구축 시간을 줄이고 배포하기 위해 사용했습니다.

oracle cloud

스킬 서버를 배포하기 위해 사용했고, 무엇보다 무료 인스턴스를 사용할 수 있었기 때문에 채택했습니다.

Project main skill

프로젝트에 구현한 주요 기능입니다.

1. 크롤링 속도 개선을 위한 멀티 프로세싱 프로그램 작성

유저가 기능을 호출할 때 서버가 매번 크롤링을 하고 카카오 챗봇에 응답하면 10초 뒤에 응답했었기 때문에 속도를 개선할 필요가 있었습니다.
크롤링 속도 개선을 위해 multiprocessing이라는 모듈을 사용했고 그 결과 대략 12초가 걸리던 응답을 2초로 개선할 수 있었습니다.
개발해보면서 처음 겪어본 속도 이슈였기 때문에 많이 당황했지만, 크롤러의 문제를 파악하고 적절한 방식으로 개선했음에 희열을 느꼈습니다.
코드 : https://github.com/jiho5993/movchatbot/blob/main/common/movie_info.py#L58

개선하기 전

2. 크롤러를 이용한 데이터 수집, 가공

request를 통해 html text를 얻어온 후, 필요한 데이터를 가져오기 위해 BeautifulSoup 크롤러를 사용하여 태그를 파싱했습니다.
실제 챗봇에서 원하는 응답으로 보여주고 싶으면 카카오 챗봇에서 제공하는 여러 응답 방식을 채택하면 됩니다.
때문에 서버에서 필요한 형태로 유저에게 응답할 데이터를 가공하고 그에 맞는 형태로 response했습니다.
코드 : https://github.com/jiho5993/movchatbot/blob/main/common/utils.py#L14

3. Docker이미지 생성 후 Oracle Cloud 배포

인스턴스에도 로컬과 똑같이 작업하던 환경을 구축해야 하지만, 실제로 구축하기 위해 발생하는 오류나 소요되는 시간이 매우 컸습니다.
Dockerfile에 작업하던 환경을 가지는 이미지를 생성하였고, 스크립트 파일을 작성하여 쉽게 배포하도록 하였습니다.
